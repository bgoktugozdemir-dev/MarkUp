# Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| ⌘O | Open Markdown in the current window or tab |
| ⌘T | Open Markdown in a new tab |
| ⌘N | Open Markdown in a new window |
| ⌘W | Close the current document/settings window |
| ⌘F | Find in document |
| ⌘G / ⇧⌘G | Next / previous match |
| ⌘A / ⌘C | Select all / copy native document text |
| ⌘+ / ⌘− / ⌘0 | Zoom in / out / actual size |
| ⌘R | Reload |
| ⌘P | Print |
| ⇧⌘E | Export PDF |
| ⌘, | Settings |
| ⌥⌘O | Toggle heading outline |
| ⌥⌘M | Toggle minimap |
| ⇧⌘H | Yellow text highlight |
| ⇧⌘U | Underline text |
| ⌘Z / ⇧⌘Z | Undo / redo annotation action; editable fields keep their native text history |

Use standard macOS Tab/Shift-Tab focus navigation. System Keyboard settings determine whether Tab includes every control. Minimap supports accessibility increment/decrement actions; outline buttons provide a keyboard alternative to pointer navigation.
