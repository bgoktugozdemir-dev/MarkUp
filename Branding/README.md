# MarkUp artwork

`MarkUp.png` is the owner-supplied 1254 × 1254 PNG received on 2026-10-31.
The macOS AppIcon asset catalog contains resized copies of this artwork in all
ten standard size/scale slots. Transparency is preserved; the artwork is not
redrawn. The older development-icon generator now defaults to an ignored build
folder so it cannot overwrite product branding accidentally.
